# Request For Comments (RFC) Process

This directory contains our Architecture and Feature Design proposals (RFCs). Before implementing any significant changes (such as database migrations, new external API integrations, or major UI redesigns), developers should write a design document and submit it here as an RFC.

## Process

1. **Create Draft**: Copy the template into a new numbered markdown file (e.g., `0002-feature-name.md`).
2. **Review**: Open a PR to discuss the design with other developers.
3. **Approval**: Once approved by reviewers, merge the document and begin implementation.
